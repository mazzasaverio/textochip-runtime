## Conventions
- Every claim traces back to evidence: a source with link and access date, a verbatim
  quote, or an experiment with a number. Mark each claim as **fact**, **customer
  opinion** or **hypothesis**.
- No personal data: roles and companies yes, names and emails no. Recordings and full
  transcripts stay outside the repo; at most an anonymized summary here.
- Layout: `trends/` (when there is no idea yet: numbered files from `00-assumptions.md`
  to `04-opportunities.md`, read in order; chosen opportunities become hypotheses),
  `hypotheses.md` (status of every hypothesis), `market/` (competitors, one file
  per close competitor, sizing), `voice/` (public customer voice by theme),
  `interviews/` (guide, one file per interview, synthesis), `experiments/` (one file per
  experiment, threshold decided before starting).
- In `trends/`, read `00-assumptions.md` before any research and discard signals outside
  its arena; a signal that contradicts an assumption is reported, not ignored.
