# Hypotheses

One row per hypothesis on the problem, the customer, the solution and the price.
Status: **to verify**, **confirmed**, **refuted**. Evidence points to an interview,
an experiment or a quote. Update the status the moment new evidence arrives.

Product-level hypotheses are in the `textochip` repository, `docs/research/hypotheses.md`;
only runtime-specific ones (boards, ports, contributors) go here.
